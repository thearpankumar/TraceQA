# traceqa-driver-webdriver

TraceQA browser driver for real Safari and for any W3C WebDriver server or cloud
grid. The `traceqa` engine starts it as a separate program and speaks the
TraceQA driver protocol with it over standard input and output.

The command is `traceqa-driver-webdriver`. This package is built from the
repository and is not published to PyPI yet; install it from a checkout
(`uv sync`). See
[docs/usage.md](https://github.com/thearpankumar/TraceQA/blob/master/docs/usage.md#drivers)
for how the engine finds drivers.
